### __程序功能__

- [x] __自定义游戏窗口的大小 (游戏需以窗口化运行)__
  - __窗口大小自适应，不会超过主屏幕工作区__
  - __窗口位置自动计算，位于主屏幕居中偏下__
- [x] __允许同时添加多个目标游戏__
  - __添加的游戏数量过多可能导致核心服务压力升高，性能开销将增加__
- [x] __配置全程可保持__
- [x] __提供通过快捷键 `F12` 切换的窗口位置锁定功能__
- [x] __配置文件支持热重载，无需重启程序__
- [x] __根据系统版本尝试修改窗口显示样式__
- [x] __提供 `CPU` 核心亲和性调整功能__
  - __该功能仅在 `Intel` 大小核架构生效 (绑定 `P-Core`)__
  - __当逻辑处理器数量超过64个 (32位系统为32个) 时，由于相关限制，该功能不会生效__
- [x] __提供启动"游戏启动器"的功能__
  - __该功能是为了防止某些启动器保护游戏进程，导致无法配置核心亲和性 (点名批评米哈游)__
- [x] __显示运行日志，可实时获知运行状态__
